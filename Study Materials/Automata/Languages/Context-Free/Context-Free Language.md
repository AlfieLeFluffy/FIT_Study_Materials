A Context-free [[Formal Language]] is a language for which it applies that:
- Generated by [[Context-Free Grammar]].
- It is accepted by a [[Stack Automata]].
The most commonly known context-free language is $L(G) = {(a^nb^n: n > 0)}$.
## Properties
### Pumping Theorem
If $L$ is a context-free language, then there exists constant $k>0$ such that if $z\in L$ and $|z|\geq k$, then $z$ can be written in form of:
$$z = uvwxy, uv\not= \epsilon,|vwx|\leq k$$
and for every $i\geq 0$ it applies that $uv^iwx^iy \in L$.
An equivalent formulation of the Pumping lemmat is:
$$L\in \mathcal{L}_{2}\implies \exists k>0:$$
$$ \forall z \in \Sigma^*:  z\in L\wedge|y|\geq \implies$$
$$(\exists uvwxy\in \Sigma^*:z=uvwxy\wedge vx\not= \epsilon \wedge|vwx|\leq k\wedge \forall i\geq_{0}:uv^iwx^iy\in L)$$
#### Proof
If $L=L(G)$ and $G$ is [[Context-Free Grammar]] in the [[Context-Free Grammar#Chomsky's Normal Form|Chomsky's Normal Form]], then:
1. First proof of the implication $A\implies^+w$ for some $A\in N$, $w\in \Sigma^*$, then $|w|\leq 2^{m-2}$, where $m$ is the number of vertexes of the longest path in the derivation tree. This implication is true, because $|w|$ is equal to the number of direct leaf predecessors of the specific derivation tree, that is at max equal to number of leaves of the full binary tree, because all branches contain $m-1$ vertexes, which is exactly $2^{m-2}$.
2. We can set $k=2^{|N|}>0$ and we are considering any brach $z$ such that $|z|\geq k$. If we set $m$ as the number of vertexes of the longest path in the corresponding derivation tree then $2^{|N|} \leq 2^{m-2}$ and such path then contains at least $|N|+2$ vertexes ($|N|+2\leq m$). From these $|N|+2$ vertexes is one terminal symbol and at least two are set by the same non-terminal symbol $A$. String $v,x$ cannot be empty, otherwise the applied rule would have a form of $A\to BC$. Now lets expect the derivation of $z$ of form $S\implies^*uAy\implies^+uvAxy\implies^+uvwxy=z$. This also means that in the grammar G there can also be made the derivation $S\implies^*uAy\implies^+uvAxy\implies^+uvvAxxy\implies^+uv^2wx^2y$, because $A\implies^+w$ is a provable statement. 
### Substitution
If $\mathcal{L}$ is a class of [[Formal Language|languages]] and $L \subseteq \Sigma^*$ is a [[Formal Language|language]] of class $\mathcal{L}$. Next if $\Sigma= \{ a_{1},a_{2},\dots,a_{n} \}$ for some $n\in \mathbb{N}$ and languages declared as $L_{a_{1}},L_{a_{2}},\dots,L_{a_{n}}$ are also part of the same class $\mathcal{L}$. We can say that $\mathcal{L}$ is closed to substitution if for a selection of languages $L,L_{a_{1}},L_{a_{2}},\dots,L_{a_{n}}$ is also a language $\sigma_{L_{a_{1}},L_{a_{2}},\dots,L_{a_{n}}}(L)$ where:
$$\sigma_{L_{a_{1}},L_{a_{2}},\dots,L_{a_{n}}}(L) = \{ x_{1}x_{2}\dots x_{m}|b_{1}b_{2}\dots b_{m} \in L\wedge i\in \{ 1,\dots, m \}:x_{i}\in L_{b_{i}}\}$$
$\sigma$ is also in the class $\mathcal{L}$.
### Morphism
If $\Sigma$ and $\Delta$ are [[Alphabet|alphabets]] and $L \subseteq \Sigma^*$ is a [[Formal Language|language]] over alphabet $\Sigma$, then:
- Mapping $h:\Sigma^*\to \Delta^*$ is called morphism over words if it applies that $\forall w=a_{1}a_{2}\dots a_{n}\in \Sigma^*:h(w)= h(a_{1})h(a_{2})\dots h(a_{n})$.
- Morphism of a language $h(L)$ is then defined as $h(L) = \{ h(w)|w\in L \}$.
Morphism of languages is a special case of substitution, where each substituted language has exactly one sentence (string).
### Closed to Operations
A class of context-free languages is closed to operation of substitution.
For context-free languages $L_{a}$ and $L_{b}$:
- Closed to operation $\cup$ which comes from substitution of $L_{a}$, $L_{b}$ into language $\{ a,b \}$.
- Closed to operation $.$ which comes from substitution of $L_{a}$, $L_{b}$ into language $\{ ab \}$.
- Closed to operation $*$ which comes from substitution of $L_{a}$ into language $\{ a \}^*$.
- Closed to operation $+$ which comes from substitution of $L_{a}$ into language $\{ a \}^+$.
- If $h$ is a specific morphism and $L_{a}'=\{ h(a) \}$ for $a\in \Sigma$ then substitution of language $L_{a}'$ into language $L$ can be obtained by language $h(L)$.
Context-free languages are closed to operations with [[Regular Language|regular languages]].
### Unclosed to Operations
Context-free languages are not closed to operations $\cap$ and complement.
### Decidable Problems
The following problems are decidable for context-free languages (through algorithmical means):
- **Empty language** problem $L(G)$ for any [[Context-Free Grammar]].
- **Affiliation** of string $w\in \Sigma^*$ into language $L(G)$ for any [[Context-Free Grammar]].
- **Finite language** problem $L(G)$ for any [[Context-Free Grammar]].
### Undecidable Problems
The following problems are not decidable (there are not algorithmical ways of solving):
- **Ekvivalence of languages of** [[Context-Free Grammar|Context-Free Grammars]] problem, where $L(G_{1})=L(G_{2})$ for two grammars $G_{1}$ and $G_{2}$.
- **Inclusion of languages of** [[Context-Free Grammar|Context-Free Grammars]] problem, where $L(G_{1})\subseteq L(G_{2})$ for two grammars $G_{1}$ and $G_{2}$.
### Regurality
[[Context-Free Grammar]] $G$ has self-insertion, if there exist $A\in N$ and $u,v\in \Sigma^*$, such that $A\implies^*uAv$ and $A$ does not have any unnecessary non-terminals. Context-free languages has the property of self-insertion, if each grammar that generates it, is self-inserting.
Context-free languages have a property of self-insertion only if if is not a [[Regular Language|regular language]]. The problem of [[Context-Free Grammar|context-free grammars]] generating a [[Regular Language|regular languages]] is not algorithmically decidable.
