A structural notation for describing and generating [[Context-Free Language]]. This grammar is used for describing and analysing programming languages (compiler's parser) and sets of string related to this. 
## Definition
It is an ordered quartet $G = (T, N, P, S)$, where:
- **T** is a final set of **terminal** symbols.
- **N** is a final set of **non-terminal** symbols where $N \cap T = \emptyset$.
- **P** is a final **set of rules** in the form of $A \to x$ where $A \in N$, $x \in (N \cup T)^*$.
- **S ∈ N** is a start symbol.
	- An example could be $G = (\{S\}, \{a, b\}, P, S)$, where $P = {S \to ε, S \to aSb}$.
	- Which can generate the language $L(G) = {(a^nb^n: n > 0)}$.
The princip is that the grammar can use rules on non-terminal symbols to generate the language. If $uAv \to uxv$ in $G$ then we can say that $G$ makes a derivation step from $uAv$ to $uvx$.
## Derivation
Similarly to [[Regular Grammar]], derivation is one step of applying rules to the current form of the word comprised of both terminal and non-terminal symbols. For context-free languages there are also two types of derivation depending on the direction in which it is done.
### Derivation Direction
Either of these directions can generate the same outcome, just in a different order.
- **Most-Left Derivation** uses the most left non-terminal to derivate.
- **Most-Right Derivation** uses the most right non-terminal to derivate.

## Properties
There are several properties tied to context-free grammars. These are:
### Ambiquity
If $G$ is a context-free grammar, then sentence $w$ generated by $G$ is ambiguous if there exist at least two derivation trees that generate sentence $w$. A grammar $G$ is ambiguous if it has at least one terminal sentence that is ambiguous. If not then the grammar $G$ is an unambiguous grammar.
## Transformations
Context-free grammars can be transformed, updated and simplified through algorithmical means. These algorithms create [[Set|sets]] of terminal and non-terminal symbols that suffice some specific conditions, such as the non-terminal symbol has a terminal sentence finish or that a non-terminal symbol is accessible.
### Non-Accessible Symbols
Non-accessible or redundant symbols are such symbols that cannot be accessed during derivation and so do not have to be part of the grammar.
### Non-Epsilon Grammar
Grammar $G$ is a grammar without $\epsilon$-rules if it does not contain $\epsilon$-rules and if $\epsilon$ is part of the [[Formal Language|language]] $\epsilon\in L(G)$ then the grammar $G$ contains only one $\epsilon$-rule from the initial non-terminal symbol $S$.
### Simple Rules
Simple rules are rules of format $A\to B$ and where $A,B\in N$. 
### Algorithms
#### Non-Terminals Generating Terminal String
Creates a set $N_{t}$ of non-terminal symbols that can end up generating a terminal string. In other words the non-terminal symbols that cycle infinitely or do not ever generate terminal symbols are excluded.
#### Available Symbols
Creates a set $V$ of non-terminal and terminal symbols that can be accessed from the initial non-terminal symbol.
#### Redundant Symbols
Uses sets $N_{t}$ and $V$ to get rid of redundant symbols from the grammar.
#### Epsilon-rules
Creates a set of non-terminal symbols that terminate in $\epsilon$ and then updates the grammar so that if the $S$ initial non-terminal symbol is part of the set then it can be derived into $\epsilon$ and no other non-terminal symbol can.
#### Simple Rules
Creates a set $N_{\epsilon}$ of non-terminal symbols that can derivate through through simple rules and the updates the grammar to no include these rules.
## Cycles
If $G$ is a context-free grammar and $A \in N$, then grammar $G$ contains a cycle if there exists derivation $A\vdash^*A$. If the grammar contains a cycle in non-terminal symbol $A \in N$ and there is exists a derivation $S\implies^* \alpha A\beta\implies^+w;w\in \Sigma^*;\alpha,\beta\in(N\cup \Sigma)^*$ then $G$ is ambiguous.
## Proper Grammar
A proper grammar is one without any redundant symbols, $\epsilon$-rules and cycles.
## Normal Forms
There are two normal forms that a context-free grammar can be in.
### Chomsky's Normal Form
A context-free gramma $G$ is in Chomsky's normal form if all rules from $P$ has one of the following forms:
- $A\to BC$, where $A,B,C \in N$
- $A\to a$, where $a \in \Sigma$
- If $\epsilon \in L(G)$ then there is only one rule $S\to \epsilon$ that generates $\epsilon$ and no other.
If there is context-free grammar $G$ then there exists a gramma $G'$ in Chomsky's normal form such that $L(G) = L(G')$.
### Greibach's Normal Form
A context-free gramma $G$ is in Greinbach's normal form if all rules from $P$ has one of the following forms:
- Has no $\epsilon$-rules.
- Each rule in $P$ including $S\to \epsilon$ has the form of $A\to a\alpha$, where $a\in \Sigma$ and $\alpha\in N^*$.
