A [[Turing Machine]] type that for each input string $w$ stops. [[Non-Deterministic Turing Machine]] are technically complete if and only if for each input string $w$ exists a finite computing brach, meaning for each input always stops.
A complete Turing machine cannot infinitely cycle.
