A universal [[Turing Machine]] type that is the basic concept of a programmable machine. It allows to define on its input a specific [[Turing Machine|Turing machine]] as a program and data over which the program should be processed/simulated.
The definition of the [[Turing Machine|Turing machine]] is done through [[Turing Machine Coding|coding]].
