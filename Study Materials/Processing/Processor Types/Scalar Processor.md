## Sub-scalar to Scalar
Sub-scalar processors do not implement [[Pipelining|pipelining]] and thus resolve [[Instruction|instruction]] one after another. Scalar processors that do implement [[Pipelining|pipelining]] and are able to process multiple instructions at the same time, each one in a different stage of completion.
