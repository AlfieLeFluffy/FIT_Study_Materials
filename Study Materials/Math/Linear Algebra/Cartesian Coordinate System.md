Cartesian coordinate system is a 3 dimensional space. Axise are usually labelled as $x$, $y$ and $z$ and each axise uses the same numbering system of with a static ratio $1:1:1$, meaning there is no distortion of the space. The space is a combination of $\mathbb{R}\times \mathbb{R}\times \mathbb{R}$.
