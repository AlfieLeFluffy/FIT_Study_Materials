## Definition
It describes the **time between two independent occurrences of a given random phenomenon**.
$$f(x) = {\alpha \times e^{-\alpha x} \ for \ x \ > 0; \ \ 0 \ for \ x \ \leq 0;}$$
$$F(x) = { 1 - \times e^{-\alpha x} \ for \ x \ > 0; \ \ 0 \ for \ x \ \leq 0;}$$
