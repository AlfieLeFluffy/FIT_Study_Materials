A type of [[Randomised Algorithms|randomised algorithm]] that:
- For every input, gives the correct result. Correctness is guaranteed.
- For every input, there is a probability that the running time is larger then the expected/desired time.
- These are for example [[Quick Sort]] or [[IRV Hiring Problem Example]]
