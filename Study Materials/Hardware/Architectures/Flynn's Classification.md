A classification of [[Von Neuman Architecture]] computers and their ability to process data over instructions in a single cycle. There are four main types:
- **SISD** - Single Instruction over Single Data
- **[[SIMD]]** - Single Instruction over Multiple Data
	- Vector [[Microprocessor|Processors]]
	- MSIMD
- **MISD** - Multiple Instructions over Single Data
- [[Multiple Instruction Multiple Data|MIMD]] - Multiple Instructions over Multiple Data
	- Multi-Thread [[Microprocessor|Processors]]
	- Multi-[[Microprocessor|Processor]] Systems (Distributed)
