Requirements for modern databases have outgrown the original database server running [[Relation Data Model]] or [[Object-Relational Data Model]]. Some of these requirements are:
- **Cloud distributed databases**
- **Problematic data types**
- **Iterative development**
- **High scaling**
In the effort to update the original relation databases to new requirements they loose their connection to the original [[Relation Data Model]] and concept. Keeping up [[ACID]] also becomes cumbersome and makes it more difficult to work with the database.
