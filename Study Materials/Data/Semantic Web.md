Represents the **web of data** unlike the web of documents (normal visible internet) onto which is *published machine-readable data*. The basic elements of this web are:
- **Representation of knowledge** such as [[Resource Description Framework]].
- **Shared conceptualization** (model of the world) is [[Ontology]]. 
- **Agents** are producers and consumers of services.
To share data through this web we already have technologies that already long in use, but integration into the already existing web is lacking, but is getting better.
## Web and Semantic Web
**World Wide Web** has as a basic unit one document, which is usually a *web page*. **Semantic Web** has as a basic unit *data*.
## Technologies
Sematic web uses technologies of the standard web. such as:
- HTTP/S
- URI
Semantic web also uses tools for representation of knowledge, such as:
- Data representation (facts)
	- XML
	- [[Resource Description Framework|RDF]]
- Sematic represenation
	- [[Ontology]]
	- Technologies to represent ontology
