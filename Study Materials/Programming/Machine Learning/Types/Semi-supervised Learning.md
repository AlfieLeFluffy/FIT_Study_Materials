# Semi-Supervised Learning
In essence it is a [[Machine Learning|machine learning]] that combines together both [[Supervised Learning]] and [[Unsupervised Learning]]. This is done through combining both annotated training data (pairs of inputs and expected outputs) with unannotated training data (only inputs). This can be useful as the unannotated examples can help to find better decision boundary between classes.
Examples of unannotated data on the internet that can be used are:
- Text
- Photos and other images
- Speech and other recordings
