An [[Instruction|instruction]] in three address code has the form of **(o, a, b, r)**, where each symbol means:
- **o** is the operator or the type of instruction such as + for sum, - for subtraction, goto for a jump, etc.
- **a** is the first operand.
- **b** is the second operand.
- **r** is the address where to store the return value.
