The basic model of functional programming is: a mathematical concept of a function applied over arguments and calculating one result, meaning the result is deterministic.
## Languages
Some common functional languages are:
- FP
- **Haskell**
- Miranda
- Hope
- Orwell
There also exist hybrid languages (imperative), such as:
- Lisp
- Scheme
- SML
