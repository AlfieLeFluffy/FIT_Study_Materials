Data structures define the specific way of organization of [[Data|data]] in computer [[Memory|memory]].
## Data Type
Data type defines a [[Set|set]] of **values** and a [[Set|set]] of **operations** over these values. The type of a variable is introduced during its declaration. A data type is defined by:
- **Name**
- A [[Set|set]] of values, which the data type can become.
- A [[Set|set]] of operations over these values.
