Control structures are a specific way [[Imperative Languages|imperative languages]] moves through and execute [[Command|commands]] within a program.
## Control Structure Types
Imperative languages implement these basic control structure types for working with commands within a program:
- **Sequence** allows for execution of commands (**assignment**, **function call**, **arithmetic operation**) one after another. Generally speaking it allows for *execution of sub-programs one after another*.
- **Selection** allows for a choice between blocks of code depending on a [[Bool's Algebra|Boolean expression]] (**if -else**, **switch**, etc.). 
- **Iteration** allows for repetition of a block of code depending on a [[Bool's Algebra|Boolean expression]] (**for**, **while**, **repeat**, **do while**, **goto**, etc.). Generally speaking it allows for *repetition of execution of sub-programs*.
### Completion
All programming languages that implement (support) these control structures and are equipped with infinite secondary [[Memory|memory]] (which is commonly ignored) are [[Turing Machine|Turing complete]].
