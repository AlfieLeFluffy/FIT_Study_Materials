The three main methods/ideas of rendering are:
- **Object** using [[Z-Buffer]] is less realistic, but really quick without shadows. This method is really useful in things such as CAD, games, virtual reality, 3D modeling.
- **Pixel** using [[Ray Tracing]]/[[Ray Casting]] is more realistic, more complex and slower, but can create sharp shadows. This method is useful in realistic pictures, medicine, realistic looking games.
- **Scene** using [[Radiozity]]/[[Particle Tracing]] is realistic but also is really slow, can create soft shadows and is used to create realistic images of scenes.
