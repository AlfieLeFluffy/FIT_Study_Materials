There are three main ways of capturing coloured images, each using either [[Charge-Coupled Device Sensor|CCD sensor]] or a [[Complementary Metal-Oxide-Semiconductor Sensor|CMOS sensor]] versions, which are:
- **Mosaic Colour Filter Array** (Bayer RGB CFA)
- **Three-CCD camera** (beam splitter)
- **Layered photon absorption** (Foveon X3)
## Mosaic Colour Filter Array
An array of coloured filters that filters light captured by the sensor. Typically there are three filters, one for each primary colour. They are arranged in a regular grid.
### Bayer's Mask
Can be done both with CCD and CMOS sensors. Today it is the most commonly used type of colour sensors.
## Three-CCD Camera
A three-CCD camera uses optical beam splitters to isolate each primary colour light (wavelength) in a different direction, which can then be captured through a CCD sensor.
## Layered Photon Absorption
Uses several layers of semi-transparent sensors (from top it goes: blue, green, red with increasing thickness). Each layer can capture only some range of light (wavelength) and light of certain those wavelength can only penetrate so deep.
