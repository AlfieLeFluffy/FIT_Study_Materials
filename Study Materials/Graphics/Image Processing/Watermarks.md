Watermarks are used to protect/identify images during [[Image Processing]]. They can be classified into several types.
## Types
Watermark are divided based on:
- **Visible/Invisible** to the naked eye
- **Method of insertion**
	- Time domain or direct change of image
	- Frequency domain or changes of the DCT coefficients during compression, changes of the spectrum
	- More
- **Type of data**
	- Binary: pseudo-random sequence, additional data
	- Image (logo): from the extracted water can be visually derived the operations that were performed above the source image
	- More
## Features
There are several features each watermark can implement or cannot implement, such as:
- Capacity (data payload): how much information can the watermark hold
- Computational Complexity: how time/space consuming the process is
- Granularity: minimal spatial-temporal interval for reliable insertion or detection
- Invisibility (fidelity): perceptibility
- Fragile/Robust
- Fault Tolerance (false positives rate, MSE)
- Security
## Methods
The basic known methods for watermarks are:
### LSB Modulation
The watermark is encoded into the [[LSB]] of each pixel in the image. The changes are almost imperceivable, but the method is not robust. Any damage to the image as higher compression or blur can destroy the watermark. The watermark can consist of pseudo-random sequence generated by a private key. 
This method can be detected by using signal correlation. For colored images the image is first converted into YUV space and the watermark is encoded into the Y channel.
### DCT Coefficients
To create a more reliable watermark when compared to LSB Modulation the DCT coefficients can be used. This is more robust and less visible in the image, but it is necessary to tamper with the compression algorithm.
There are several ways of embedding/changing of the coefficients. Several coefficients can be chosen based on their location within the DC space. Changing of only one coefficient is quite noticeable within the image and so several coefficients must be chosen and the watermark must be encoded over them.
### Disjoint Sets
Methods using disjoint sets split the image into two equal large [[Set|sets]] of pixels A and B. The selected bounding pixels are the private key. Subsequently the algorithm increases the brightness of the pixels in section A by k and in section B it decreases by k. The changes are rather small and practically unperceivable.
Detection is done by splitting the resulting image by the private key, computing the average intensity of each section and if the watermark is present their difference should be 2k.
### MD5
The basic idea is thus: the image is divided into blocks of 8, least significant bits are removed, the rest of the bits are concatenated with a parameter dependent on image size and private key, the MD5 checksum is combined with the binary image of the watermark and the result is inserted into the image as the least significant bit.
This allows for pixel-wise detection of modifications and the watermark can be used to prove authenticity.
