#UI
**Communication channels** are ways of **communication between a user and a computer** (machine). For this the computer uses peripheral devices such as a monitor, keyboard, computer mouse, camera, printer, etc. These peripheral devices use a combination of **human senses** to transfer information.
## Computer to User
These include:
- **Image** (sight) is the **most common** channel a computer uses to display information. It has the **most information throughput** as it is a sense we train the most for information transferring.
- **Sound** (hearing) is useful for lower amount of information as it has less information throughput, but it is really good for **notifications**. Sound also is a somewhat [[Serial Interface]] as more streams of information at once can overwhelm the user and make them unable to pay attention, but still allows for some parallel information like a music and a message notification at the same time.
- **Touch** can be used in many ways. As accommodation for blind people it can be used as **braille**. Another form can be feedback for actions or events in the form of **vibrations**.
- **Smell** and **taste** are not usually used and are ill-suited for computer communication, but there are some devices that use these for testing. The main problems with these channels are synthetizing these feeling in real time and require chemicals that need to be refiled frequently. 
## User to Computer
These include:
- **Touch** (Movement) is the **most common** way of user input. This includes things such as keyboards, computer mousse, buttons, but also spatial inputs such a motion tracking like VR headsets and controllers, motion capture suits (ones using only movement and not cameras), etc.
- **Sound** (Speech) is now already a viable communication channel used especially in assistants and speech to text conversions. These are usually tuned towards English and other common languages such as Mandarin. There is also an issue with privacy as the data from these systems are usually used for further training and sensitive things line passwords or personal information is not suitable for this.
- **Image** (Vision) are used in thing like **gestures**, **motion capture** (for games, films, avatars, etc.).
- **Biometric** data is used in many ways and usually transmitted through some of the channels mentioned above, but it seems to deserve its own category. This can be used for things such as **fingerprint** scanners, **temperature** checks, **patient monitoring** like heartbeat and blood pressure, etc.
