#UI
There are two things that can be considered **modes of communication** and that is how the system and the user exchange information and how the user can change how the system interprets input.
## System User Dynamic
There two main dynamics used in communication between user and system:
- **Active Communication** is where the user controls the actions of the system. In other words the system is under the will of the user, such as graphic editors, terminals, etc.
- **Passive Communication** is where the user responds to the questions of the system and has little possible options to influence the system, such as dialogue popups.
It is certain that not all communication with a system/computer will be only active or passive and a combination of these dynamics is necessary. Some activities are easier done in active mode and some are better done in passive.

| Property        | Active Communication     | Passive Communication |
| --------------- | ------------------------ | --------------------- |
| Effective work  | depending on application | often ineffective     |
| Learning        | difficult                | easier                |
| Creative work   | easier                   | difficult             |
| Possible errors | big                      | small                 |

## User Set System Modes
Computers can have more then one communication mode, depending on special inputs that can be added. These are toggle buttons like **Casplock, Numlock, Insert** and other keys that change the keyboards and other peripheral inputs like **Shift, Control, Windows key**.
## Drag and Drop
Also known as **direct manipulation** allows users to directly interact with elements on screen, such as changing position of elements, their size, etc. This supports the users natural behaviour and allow for easier interactions with a computer for untrained users. It allows lower the requirements for a skilled user and allows for tedious work to be simplified, like moving objects in a graphic editor.
