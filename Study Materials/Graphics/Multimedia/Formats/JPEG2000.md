The successor image format to [[JPEG]] (separate incompatible implementation). The format is defined by [[International Organization for Standardization|ISO]]/[[IEC]] 15444-1.
## Characteristics
Some basic characteristics:
- Many upgrades when compared to [[JPEG]]
	- Better quality with same [[Compression|compression]] ratio
	- Computationally more complex
- Loss/lossless [[Compression|compression]]
- Based on [[DWT]]
- Resistant to some damage/error because of the separate layer architecture
- Allows for different degrees of quality during decoding both globally and locally
## Encoding
The basic encoding pipeline is:
1. Image is preprocessed
2. Image is split into tiles
3. Each tile is decomposed through DWT
4. Each tile is quantized through ROI
5. Each tile is encoded through [[EBCOT]]
The input is the image within the [[YCbCr]] color space. The [[DWT]] uses a spline wave. The output data stream is divided into layers, where each layer contains packets of blocks from a certain layer of the DWT transformation of the tile.
